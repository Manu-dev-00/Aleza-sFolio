Information du projet

  • Catégorie: Développement Web
  • Nom du projet: Météo_Soft
  • Type de projet: Expérience professionnelle (stage chez METEO TOGO)

Description

Météo_Soft est une application de tableau de bord météo moderne et élégante qui fournit des informations météorologiques en temps réel, des prévisions et des données géographiques pour les villes du monde entier.

🎯 Fonctionnalités principales

  • Météo actuelle : température en temps réel, conditions météorologiques et heure locale.
  • Prévisions : évolution de la température sur 24 heures, prévisions horaires et prévisions sur 7 jours avec températures minimales et maximales.
  • Métriques détaillées : indice UV, vitesse du vent, humidité, visibilité, température ressentie, heures de lever et de coucher du soleil.
  • Recherche de ville : recherche rapide de n’importe quelle ville du monde.
  • Cartes interactives : carte de localisation de la ville et fenêtre de détails du pays (population, capitale, devise, données régionales).
  • Journal météo personnel : enregistrement de son ressenti du jour (niveau de confort et notes).
  • Consensus multi-modèles : comparaison de plusieurs prévisions de température, avec moyenne, écart et variance.

🛠️ Technologies utilisées

  • Structure et style : HTML5, CSS3 (effet de verre dépoli) et Tailwind CSS.
  • Logique et interactions avec les API : JavaScript.
  • Cartographie : Leaflet.js.
  • Icônes : Lucide Icons.
  • API de géocodage Open-Meteo : recherche de villes et coordonnées.
  • API météo Open-Meteo : données météorologiques et prévisions.
  • API REST Countries : informations et détails sur les pays.
